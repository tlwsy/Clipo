# Clipo v0.1.0

自托管网页采集与 AI 笔记的首个版本。支持 PWA、浏览器扩展和 iOS 快捷指令录入，模型不可用时保留原文。

- 小红书、小黑盒、B 站、YouTube 提取器，评论采集上限及 AI 评分；扩展可直传当前页面内容。
- 标签、收藏、中文检索、最近 50 篇笔记离线阅读与离线操作恢复。
- 完整笔记库 JSON/Markdown 导出、事务性 JSON 回导，本地／S3 兼容／WebDAV 手动和定时备份。
- Docker Compose 静态部署、PostgreSQL 16、独立 Huey worker；默认关闭注册。

## 安装与升级

下载源码后运行 `python3 scripts/init_env.py`，然后 `docker compose up --build -d --wait`，打开 `http://localhost:8000`。详细步骤见 [README](https://github.com/tlwsy/Clipo#readme)。升级已有实例先保留数据库及主密钥；启动会自动迁移至 `0011_backup_jobs` 并启动 API/worker。

附件 `clipo-extension-0.1.0.zip` 解压后在 Chrome/Edge 开发者模式加载；不是商店发布包。`SHA256SUMS` 用于检查下载完整性。

公开镜像：`ghcr.io/tlwsy/clipo:v0.1.0`（linux/amd64），支持匿名拉取。GitHub CI 已通过后端 382 项、前端 24 项、扩展 5 项，以及 PostgreSQL 22 项、浏览器双实例恢复和空 Compose 首次部署；实际 MinIO/WsgiDAV 上传读取也已验证。

## 已知限制

- 真实登录小红书/小黑盒的扩展及 Edge、Android 系统分享仍待实机验收；YouTube 线上验收受当前测试环境 DNS 限制。
- 评论仅限实际可获取的顶层评论与账号上限，不能保证取得平台全部评论。
- 媒体只保存外链，备份恢复链接而非图片文件；JSON 单包上限 100 MiB，整个实例恢复仍需数据库与主密钥。
- 已实测 MinIO 和 WsgiDAV 的备份读写；其他 S3/WebDAV 提供商须核对 endpoint、认证和目录权限。
- iCloud 快捷指令发布版本已获用户 iOS 实机确认；仓库未签名模板的 Mac 签名与导入未另行验证。

精确的本次测试和待验收范围见 [构建进度](https://github.com/tlwsy/Clipo/blob/main/docs/progress.md)。
