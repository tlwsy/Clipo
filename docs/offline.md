# 离线阅读与同步

需要 HTTPS 或 localhost，并使用生产静态构建（`make build` + `make serve`，或 Docker）。开发服务器不注册 Service Worker。

登录后打开应用，后台自动缓存最近 50 篇笔记的正文、摘要、评论和标签，顶部显示实际已缓存数量。待缓存完成再断网；离线时可以重新打开首页和详情、搜索已缓存内容、按标签/收藏筛选。未缓存的笔记会提示联网打开；图片仍为原站外链，不下载图片或视频。

离线收藏、删除和提交链接保存在本机 IndexedDB。保持应用打开或再次打开后，恢复网络会按原顺序重放；链接保留原幂等键，删除已不存在的笔记视为成功。顶部显示待同步数量及失败原因，可点击“重试同步”；无法完成的操作可选择“取消失败操作”，再继续后续同步。同步前会核对在线账号，其他账号不会执行旧账号操作；失败操作保留，后续操作等待前一项完成。标签编辑和设置需要联网。

Access Token 仍仅在内存，刷新 Cookie 仍为 HttpOnly；离线库不保存密码、Token 或平台 Cookie。缓存是当前浏览器可读的数据，请只在可信设备使用。切换账号、服务器明确拒绝认证、成功退出登录会清理缓存及待同步操作，退出前若仍有待同步操作会要求确认。浏览器清理站点数据、存储配额不足或隐私模式限制可能使离线不可用；已在服务端保存的笔记不受影响。

Service Worker 缓存页面和构建资源，受保护 API 不进入 Cache Storage。笔记读取采用 2 秒联网优先，网络失败回退本账号缓存；401 不使用缓存绕过登录。重新打开离线缓存并不意味着在线会话已续期。

有新版本时显示“刷新应用”，用户点击后才激活新 Service Worker。待同步队列保存在 IndexedDB，刷新不清除；新构建使用独立缓存版本。应用打开时每分钟检查更新和刷新缓存，待同步操作每 5 秒重试；关闭应用后不保证系统后台执行。
