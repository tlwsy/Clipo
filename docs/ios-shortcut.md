# iOS 快捷指令 (Shortcut) 指南

Clipo 为 iOS / iPadOS 用户提供了专属的快捷指令集成，支持在系统任意应用中通过“分享菜单”或“剪贴板自动识别”将内容一键保存至自托管的 Clipo 知识库。

---

## 核心特性

- **免密自动配对**：服务端生成 5 分钟有效的一次性配置码，快捷指令自动领取服务器地址与专用 API Token，告别在移动端手动复制粘贴长密钥的繁琐操作。
- **系统分享无缝衔接**：在 Safari、小红书、小黑盒、B站、YouTube 等 App 中点击系统分享菜单，直接保存内容。
- **剪贴板智能抓取**：当目标应用（如小红书、小黑盒部分版本）仅提供“复制链接”时，直接点击运行快捷指令，将自动读取剪贴板中的首个有效 URL 并提交入库。

---

## 安装与快速配置

### 第一步：安装官方快捷指令
通过苹果官方 iCloud 链接获取预制好的快捷指令：
👉 **[点击安装“保存到 Clipo”快捷指令](https://www.icloud.com/shortcuts/0cfcf8c51dcc4c2f9bc6d621e5d2dd09)**

### 第二步：设备一键配对
1. 使用 iPhone / iPad 上的 Safari 浏览器打开你的 Clipo 网站，登录你的账号；
2. 进入 **设置 (Settings) -> iPhone 快捷指令** 区域；
3. 为当前手机填写一个设备备注（如 `My iPhone 15`），点击 **“生成设备配置”**；
4. 点击 **“打开快捷指令并配置”**，系统将自动唤起快捷指令并写入服务器连接配置；
5. 在手机弹窗中确认允许网络和文件访问，等待提示“Clipo 配置已保存”即可。

> **备选方案**：若系统未能自动唤起，可复制设置页中的配置文本，手动运行一次快捷指令完成配对。
