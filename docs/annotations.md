# 编辑与标注

Q4 第二阶段为已保存的正文增加私人高亮、批注及阅读样式，不修改采集原文或 AI 摘要。数据库迁移为 `0018_annotations`，兼容 SQLite 与 PostgreSQL。

## 使用方法

1. 打开笔记，在“原始正文”选择同一内容块内的文字，点击浮动工具栏的颜色即保存高亮，或点“添加批注”输入想法再保存。需要带颜色的批注，可先打开批注输入，再选择颜色。
2. 点击“我的标注”查看选区预览、批注及创建时间；点击预览跳回原文，折叠正文会自动展开。侧栏支持修改颜色和文字，删除需确认。重叠选区保留每条标注，最新的有色标注优先显示，悬停可查看该片段的批注。
3. 点击“阅读样式”，选择“仅本文”或“所有笔记”，使用预设或展开“高级调整”；预览确认后保存。点击“本文跟随全局”清除这篇笔记的覆盖。移动端侧栏位于正文上方，样式面板可滚动。

样式仅应用于“原始正文”；标题、工具栏、AI 摘要与评论保持原有界面。保存失败会显示错误并保留当前批注草稿，关闭工具栏或离开页面会放弃未保存的输入。

## 数据与接口

- `POST/GET /api/v1/notes/{note_id}/annotations`：创建、列出标注。
- `PATCH/DELETE /api/v1/annotations/{annotation_id}`：修改颜色/批注、删除。
- `GET/PATCH /api/v1/user/reading-preferences`：获取、调整全局阅读偏好。
- `PATCH/DELETE /api/v1/notes/{note_id}/display`：调整本文覆盖、恢复跟随全局。
- 私有笔记详情包含 `annotations`、`reading_preferences` 和 `display_overrides`。公开分享不包含以上私人数据。

沿用现有整数 ID。所有仓储读写检查认证账号及所属笔记；删除笔记或账号级联删除标注。每篇最多 1000 条标注，每条选区最多 10000 个 UTF-16 单元、批注最多 5000 字。至少保留颜色或非空批注；可重叠标注，删除单条不影响其他条目。

`block_index` 是所有内容块（包括结构容器、图片）的 **0 起始前序编号**。列表项、表格单元格、引用、标题及折叠内容均使用同一编号规则。偏移为该块自身文本的 UTF-16 单元 `[start_offset, end_offset)`，与浏览器 Range/JavaScript 字符串一致；富文本使用各 inline 文本拼接，代码块使用 `text`。不把子块文字、图片说明或游戏卡片操作按钮算进父块选区。没有结构块的旧笔记以整篇 `content.text` 为块 0。

创建时服务端验证范围并保存原文片段 `selected_text`；客户端提供片段时必须匹配，不能截断 emoji 的代理对。不同块之间的选区需分开标注。原文不变时重新生成摘要不会改变标注；重新采集是新笔记，不自动搬迁标注。

## 阅读样式

提供舒适、紧凑、专注、打印四个预设，以及字体、字号、字重、行距、段距、内容宽度、对齐、背景和文字颜色。颜色仅接受六位十六进制值，字体使用固定枚举，不接受任意 CSS 或资源地址。

全局偏好是账号范围；单篇只保存覆盖字段。PATCH 未传字段保持原值，`null` 移除该项覆盖；传入 `theme` 会先清空当前范围旧覆盖，再应用该预设及同次提交的字段。本文没有主题覆盖时继承全局；本文指定主题时从该预设起应用本文覆盖。删除本文样式后再次跟随全局。

## 备份与边界

资料库 JSON 保存完整标注、时间、本文覆盖和全局阅读偏好，Markdown 增加“我的标注”列表。恢复重新分配笔记与标注 ID，保持选区和批注；任何无效选区、重复标注或非法样式使整个导入失败。向已有账号追加恢复时保留其已配置的全局阅读偏好；目标尚未配置时使用归档偏好。旧归档缺失字段按空数据处理，新归档需要支持标注的 Clipo 版本。

标注和样式写入需要联网，不加入现有离线写队列。缓存笔记可保留最近一次同步的标注和样式；其他设备的后续修改需联网重新打开后可见。打印预设仅调整阅读样式，单篇 Markdown/HTML/PDF 导出属于下一阶段。

本阶段分节点验收记录见 [构建进度](progress.md)。复验命令：先运行 `make build`，再运行 `uv run --no-project --with playwright python scripts/smoke_annotations.py`；双实例备份使用 `scripts/smoke_backup.py`。脚本仅使用临时数据库、离线正文和固定模型，浏览器手机视口不等同于 Android/iOS 实机验收。
