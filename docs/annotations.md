# 编辑与标注

Q4 第二阶段为已保存的正文增加私人高亮、批注及阅读样式，不修改采集原文或 AI 摘要。数据库迁移为 `0018_annotations`，兼容 SQLite 与 PostgreSQL。

## 使用方法

1. 打开笔记，在“原始正文”选择同一内容块内的文字，点击浮动工具栏的颜色即保存高亮，或点“添加批注”输入想法再保存。需要带颜色的批注，可先打开批注输入，再选择颜色。
2. 点击“我的标注”查看选区预览、批注及创建时间；点击预览跳回原文，折叠正文会自动展开。侧栏支持修改颜色和文字，删除需确认。重叠选区保留每条标注，最新的有色标注优先显示，悬停可查看该片段的批注。
3. 点击“阅读样式”，在“主题 / 字体 / 排版”三个页签中调整。主题提供配色色卡和整套预设；字体使用可视选项，字号、宽度和间距使用滑杆。预览显示当前笔记的标题、摘要与完整文字正文；确认后选择“仅本文”或“所有笔记”并保存，两个范围分别保留本次草稿。点击“本文跟随全局”清除这篇笔记的覆盖。桌面并排显示预览和设置，两栏独立滚动，预览填满可用高度；手机上下排列，预览与配置分别滚动，分类页签与保存按钮保持可访问。细滚动条、选项滑动与预览过渡遵循系统“减少动态效果”设置。

阅读配色覆盖整张私人笔记，包括标题、摘要、正文、评论和对话区域；字体、字号、行距及对齐用于阅读内容，标题保留相应的字号层级，内容宽度统一约束各区块。操作按钮和编辑弹窗保持适合交互的字号与清晰配色。调整仅影响弹窗内预览，保存后才应用到笔记；关闭或按 Esc 放弃未保存的调整。保存失败显示错误并保留草稿，可直接重试。私人标注仍仅对原始正文操作。

## 数据与接口

- `POST/GET /api/v1/notes/{note_id}/annotations`：创建、列出标注。
- `PATCH/DELETE /api/v1/annotations/{annotation_id}`：修改颜色/批注、删除。
- `GET/PATCH /api/v1/user/reading-preferences`：获取、调整全局阅读偏好。
- `PATCH/DELETE /api/v1/notes/{note_id}/display`：调整本文覆盖、恢复跟随全局。
- 私有笔记详情包含 `annotations`、`reading_preferences` 和 `display_overrides`。公开分享不包含以上私人数据。

沿用现有整数 ID。所有仓储读写检查认证账号及所属笔记；删除笔记或账号级联删除标注。每篇最多 1000 条标注，每条选区最多 10000 个 UTF-16 单元、批注最多 5000 字。至少保留颜色或非空批注；可重叠标注，删除单条不影响其他条目。

`block_index` 是所有内容块（包括结构容器、图片）的 **0 起始前序编号**。列表项、表格单元格、引用、标题及折叠内容均使用同一编号规则。偏移为该块自身文本的 UTF-16 单元 `[start_offset, end_offset)`，与浏览器 Range/JavaScript 字符串一致；富文本使用各 inline 文本拼接，代码块使用 `text`。不把子块文字、图片说明或游戏卡片操作按钮算进父块选区。没有结构块的旧笔记以整篇 `content.text` 为块 0。

创建时服务端验证范围并保存原文片段 `selected_text`；客户端提供片段时必须匹配，不能截断 emoji 的代理对。不同块之间的选区需分开标注。原文不变时重新生成摘要不会改变标注；重新采集是新笔记，不自动搬迁标注。

## 阅读样式

提供白纸、暖纸、柔绿、雾蓝、深色五种配色，以及自定义背景与文字颜色。配色只改变颜色，不重置字体与排版。舒适、紧凑、专注、打印四个整套预设会同时重置字体、字号、字重、行距、段距、内容宽度、对齐与颜色。颜色仅接受六位十六进制值，不接受任意 CSS 或资源地址。

- **跟随系统**：依据浏览器的系统明暗偏好自动切换整张私人笔记，并实时响应变化。
- **莫奈取色**：选择种子色，或从本机 JPG/PNG/WebP/AVIF 图片（不超过 12 MB）提取主色，再生成柔和背景、文字与强调色。支持浅色、深色及随系统。使用 [Material Color Utilities](https://github.com/material-foundation/material-color-utilities) 的量化、颜色评分与 HCT 色调算法；图片仅在浏览器处理，不上传、不保存图片或文件名，跨设备只同步种子色及明暗偏好。
- **在线字体**：展开“在线字体库”，从 [Fontsource 目录](https://fontsource.org/docs/api/fonts) 按英文名称或常见中文别名（如“思源黑体”）搜索，默认筛选支持中文的字体，也可切换全部语言。选择后按固定版本从 jsDelivr 的 Fontsource npm 包加载 CSS/字体；保留中文分片的 `unicode-range`，按需下载。推荐思源黑体 / 思源宋体，可使用 400、500、600、700 四档字重。只启用字体目录实际支持的档位；本机字体提供标准与加粗，避免设备缺少中间字重时出现两档相同。仅支持拉丁文字的字体保留中文回退。
- 字体目录与首次下载需要互联网；加载中和失败均有提示，失败使用本机回退并可重试。已加载字体由浏览器正常缓存，不保证离线可用，也不纳入 PWA 离线缓存。目录请求不携带账号凭据或笔记内容，字体资源 URL 不包含笔记正文。

全局偏好是账号范围；单篇只保存覆盖字段。PATCH 未传字段保持原值，`null` 移除该项覆盖；传入 `theme` 会先清空当前范围旧覆盖，再应用该预设及同次提交的字段。本文没有主题覆盖时继承全局；本文指定主题时从该预设起应用本文覆盖。删除本文样式后再次跟随全局。新增 `color_mode`、`monet_seed`、`monet_scheme`、`online_font`（ID、字体名称、版本、可变字体标记与支持字重）均存于现有 JSON 字段，无新迁移；旧笔记和旧备份保持原配色与本机字体。

## 备份与边界

资料库 JSON 保存完整标注、时间、本文覆盖和全局阅读偏好，Markdown 增加“我的标注”列表。恢复重新分配笔记与标注 ID，保持选区和批注；任何无效选区、重复标注或非法样式使整个导入失败。向已有账号追加恢复时保留其已配置的全局阅读偏好；目标尚未配置时使用归档偏好。旧归档缺失字段按空数据处理，新归档需要支持标注的 Clipo 版本。

标注和样式写入需要联网，不加入现有离线写队列。缓存笔记可保留最近一次同步的标注和样式；其他设备的后续修改需联网重新打开后可见。打印预设仅调整阅读样式，单篇 Markdown/HTML/PDF 导出使用其独立的导出排版，不加载私人阅读在线字体。

本阶段分节点验收记录见 [构建进度](progress.md)。复验命令：先运行 `make build`，再运行 `uv run --no-project --with playwright python scripts/smoke_annotations.py`；双实例备份使用 `scripts/smoke_backup.py`。脚本仅使用临时数据库、离线正文和固定模型，浏览器手机视口不等同于 Android/iOS 实机验收。

阅读外观专项：`python scripts/smoke_reading_appearance.py` 使用离线字体目录夹具并验证下载失败回退；`--online-fonts` 显式访问真实 Fontsource/jsDelivr，额外核对中文可变字体四档字形。
