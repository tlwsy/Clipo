# 回忆廊

在主导航点击 **回忆**，进入一次显示一篇笔记的全屏卡片。卡片显示标题、摘要（无摘要时显示原文片段）、要点、来源、保存日期及推荐理由。阶段完成状态及本次验证见 [构建进度](progress.md)。

## 使用

- **跳过**或左滑：只在本轮前进，不隐藏这篇笔记。
- **打开阅读**或点击标题/摘要：进入原有笔记详情；实际打开后，7 天内不再推荐。
- **收藏**：切换收藏状态；右滑会标记收藏并前进，复用既有收藏及离线同步机制。
- 右上角 **×**：30 天内不再推荐，笔记仍保留。操作成功后才移除卡片，失败可以重试。
- 键盘 **← / →** 切换，**Esc** 或“关闭”退出；最后一篇后可重新抽取。没有候选时显示筛选条件说明。

回忆推荐和移除需要联网，离线时有明确提示与重新加载入口。候选只保留在当前页面内存，关闭后重新抽取，不加入最近 50 篇离线缓存；打开阅读后正文仍沿用既有离线缓存机制。

## 阅读记录

只有私有笔记详情页可见、获得焦点且浏览器在线时累计阅读时长；打开时上报 0 秒，每 15 秒及失焦/隐藏/离开时上报增量。后台标签页和浏览器离线期间不计时，设备挂起后单段最多计 30 秒。上报复用账号核对和认证续期，离开时使用 `keepalive` 请求；网络失败、系统强制关闭或卸载时续期失败可能丢失尚未确认的时间，不进入离线写队列、不自动重试增量请求。多个设备同时阅读会累加，不合并重叠时间。

## 推荐规则

- 最近 7 天未打开过，包括从未打开的笔记。
- 至少满足一项：有私人标注、有非空 AI 摘要、累计阅读超过 120 秒。
- 从符合条件的内容中无重复随机抽取，默认最多 15 篇（可指定 10–15）；不足时返回实际数量，无候选时返回空列表。
- 保存越久，抽取概率越高，权重为 `1 + 保存年数`。采用流式加权采样，只保留选中的 ID；筛选扫描仍随账号笔记量增长，尚未进行大规模性能验收。
- 移除表示从回忆中隐藏 30 天，笔记正文、标注和收藏仍保留；再次移除会重新计算 30 天。到期后立即重新具备候选资格，不依赖清理任务运行。

## 接口和数据

三个接口均要求登录会话或 API Token，仓储读写限定当前账号，响应禁止缓存：

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/memory-gallery?count=15` | 摘要片段、最多 5 条要点、来源、保存时间、标注数量和收藏状态 |
| `POST /api/v1/notes/{note_id}/view` | `{"duration_seconds":30}`，累加本段阅读秒数并更新最近打开时间；0 秒用于记录打开 |
| `POST /api/v1/memory-gallery/dismiss` | `{"note_id":42}`，隐藏 30 天，重复请求更新同一条记录 |

阅读上报仅接受 0–300 的整数秒数，SQL 原子累加以保留多标签页/设备并发增量，总秒数最大为 2147483647。上报采用增量语义，不自动重试不确定的成功请求。读取详情、列表预加载、备份、导出和公开分享均不会自动产生阅读记录，阅读也不修改内容更新时间或触发嵌入生成。

迁移 `0020_memory_gallery` 为笔记添加 `last_viewed_at`、`reading_duration_seconds` 和最近打开索引，新增 `memory_gallery_dismissals`。兼容 SQLite/PostgreSQL，升级后的旧笔记默认从未打开、累计 0 秒。回滚会删除新增历史与移除记录，保留正文和既有关联。Huey worker 每天 03:00 UTC 清理过期移除记录；停机不影响过期筛选，下次计划执行会清理。

私人阅读历史及移除时间随 `library.json` 保存，恢复时映射新笔记 ID，不出现在公开分享或单篇 Markdown/HTML 中。旧备份缺少这些字段时使用空历史；新备份需导入支持回忆的版本，旧版本会拒绝额外字段。阅读历史不是精确的跨设备计时或审计数据。
