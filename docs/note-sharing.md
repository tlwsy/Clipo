# 笔记重新摘要与公开分享

## 重新生成摘要

在笔记详情点击“重新生成摘要”。后台使用这篇笔记保存的原文和评论、执行时的模型配置重新整理，不请求来源网站。需要联网，并可能产生模型费用。

同一篇笔记只运行一个摘要任务；刷新或重启后可继续查看状态。成功更新本篇摘要、要点、建议标签和评论评分，原文、笔记 ID、收藏、手动及原有标签保留，新建议标签追加。失败保留旧结果；单独评分失败保留旧评分并提示。未配置模型时直接失败，配置后点“重试摘要”；其他失败最多自动执行 4 次，间隔 30/120/480 秒，之后可手动重试。

## 创建与撤销分享

在笔记详情展开“公开分享这篇笔记”，确认可见范围后创建链接。默认 7 天，可选 1 天、30 天或永久。每篇最多 10 个有效链接，可分别撤销。完整链接仅创建时显示，请当场复制；之后可管理有效链接但不能取回凭据，丢失时撤销并重新创建。

持有完整链接的人无需登录即可看到：标题、原始正文、摘要、要点、来源地址、作者、发布时间、图片链接、全部已保存评论和评分。账号信息、笔记内部 ID、标签、收藏、保存时选区、原始 HTML、任务及模型错误不会出现在公开接口。图片按需点击，页面不自动加载外部图片；HTML 不直接渲染。

分享的是当前笔记，之后重新摘要成功的结果也会公开。撤销、到期或删除笔记后，后续接口请求立即失效；已经打开的页面每 30 秒复查，在切回页面时也重新验证。公开内容不写入离线笔记库；离线后清除当前展示。撤销不能收回访客自行截图、复制或下载的内容。

分享链接形如 `/public/#凭据`，必须连同 `#` 后内容完整复制。片段不会随页面导航或普通外链 Referer 发送；浏览器以 POST 正文向匿名读取接口提交凭据，服务器仅保存 SHA-256 哈希。请勿在反向代理或监控中记录请求正文。公开页及接口返回禁止缓存、禁止索引和 `no-referrer` 标头；搜索引擎是否遵守索引指令仍由其自身决定。

笔记 JSON/Markdown 导出不包含分享凭据或授权，恢复到其他实例后需要重新创建分享链接。数据库完整备份仍含分享哈希与有效期；恢复该数据库会恢复备份时的授权状态。

## 部署和验收

升级需执行 `make upgrade` 并重启 API/worker；本阶段迁移为 `0012_summary_jobs`、`0013_shared_links`、`0014_access_buckets` 与 `0015_summary_request_keys`。回滚会删除对应任务、分享授权、计数或请求映射，保留笔记。最后一项为合并请求保存幂等映射，并为旧任务回填原请求键。Web 页面保持静态导出，详情为 `/notes/?id=42`，匿名页面为 `/public/#凭据`。

`scripts/smoke_notes.py` 使用临时数据库、独立 API/worker 和固定模型验证页面链路。自动化结果只证明本地功能，不代表真实模型质量或此前平台/设备待验收项通过。

## 访问频率保护

| 操作 | 每个 60 秒窗口上限 |
| --- | --- |
| 匿名读取分享（包括无效凭据与格式错误） | 实例总计 600 次，每个来源地址 60 次 |
| 重新生成摘要及手动重试 | 每个账号合计 6 次 |
| 创建分享链接 | 每个账号 10 次 |

超限返回统一错误体、HTTP 429、`Retry-After` 标头及 `error.detail.retry_after`（秒）。摘要重放和合并提交也计数，但不会重复运行模型；读取状态、查看私有笔记及撤销分享不消耗这些配额。相关 POST 请求正文最大 4096 字节，超限返回 413，支持无 Content-Length 的流式请求。

计数写入应用数据库，多个 API 进程及重启共用；只保存以主密钥 HMAC 处理后的主体键和计数，不保存明文 IP 或分享凭据。过期计数在下一次限流操作时清理；实例总限额也限制匿名来源记录的增长。该保护限制应用层操作，仍需由部署层负责连接数、带宽和全站防护。

来源地址取 ASGI 服务端提供的客户端地址，应用本身不解析 `X-Forwarded-For`。反向代理部署时仅信任实际代理的地址，勿将 Uvicorn 的 `FORWARDED_ALLOW_IPS` 设为 `*`；未信任代理时访客可能共用代理地址的配额。当前默认限额固定于 `backend/app/security/note_limits.py`，不通过用户设置调整。
